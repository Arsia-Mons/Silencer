# Lobby UI baselines

Legacy lobby PNG references retained for the parts of the Clay lobby that still
aim for legacy pixel parity. Generated by `capture.sh`.

## Current state

The only committed legacy baselines still in active use here are:

| Baseline           | Source state                                      |
|--------------------|---------------------------------------------------|
| `title_chrome.png` | default lobby frame right after LOBBY-state entry |
| `character.png`    | same frame as `title_chrome.png`                  |

The right-pane legacy baselines (`gameselect`, `gamecreate`, `gamejoin`,
`gametech`) were retired. They encoded the old two-box chrome and produced
false confidence once the intended stepped L-shape diverged from legacy.
The real stepped pane is now guarded by
`tests/lobby-ui/lobby_stepped_pane_test/run.sh` against a committed current-UI
reference instead of a legacy screenshot.

## Reproducing

```bash
# Build both legacy halves first:
clients/silencer/build.sh win-ninja
(cd services/lobby && go build -o lobby .)

# Capture:
bash tests/lobby-ui/baselines/capture.sh
```

The script boots a local lobby on an ephemeral port + a headless
silencer pointing at it, logs in as a synthetic user, and writes the
PNGs into this directory.
