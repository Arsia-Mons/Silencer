Silencer launcher — interactive prototype

Starts from a fresh machine (nothing installed). Header is brand + links + optional account: SIGN IN opens a popover (the lobby auto-registers new usernames, so one form covers everyone); signed in, the chip opens account actions and the game launches pre-authenticated. MANAGE ACCOUNT and forgot-password take over the content panel — an email on file (optional) is the only path to password reset. The bottom bar carries everything linked to playing: ping, and a split button — channel segment (opens the drop-up: per-channel status, INSTALL/UPDATE actions, install location defaulting to next to the launcher, still CHANGE-able; installs land in {dir}/{channel}) fused to the primary action, which reads INSTALL until the active channel exists, then PLAY. The content panel has NEWS | RELEASES tabs — the same list/detail layout for both, releases following the active channel.
