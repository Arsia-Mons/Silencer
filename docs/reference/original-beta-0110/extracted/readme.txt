=======================
I. MINIMUM REQUIREMENTS
=======================

- Win95 or Win98
- Pentium 200 or faster processer
- DirectX 7.0 or higher
- 32 MB of RAM
- 30 MB of hard drive space
- Internet connection required for non-tutorial play


============================
II. GENERAL TECHNICAL ISSUES
============================

Silencer requires DirectX 7.0 or higher.  If you do
not have DirectX 7.0 or higher installed on your 
computer you can download it from Microsoft at the
following URL:

http://www.microsoft.com/directx/homeuser/downloads/default.asp

This is a BETA version so there will be bugs and
visual anomolies that will not exist in the final
version.  Please refer to the Silencer web page
for a list of known bugs / issues.  You can report
bugs via the Bug Reporting Form found at

http://www.won.net/channels/action/silencer/feedback.asp
